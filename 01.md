# 🚀 Mars Attack - Déploiement Example Voting App avec Ansible

## Objectif

Ce TP consiste à faire évoluer le projet **Mars Attack** afin de déployer automatiquement l'application :

https://github.com/dockersamples/example-voting-app

en utilisant les bonnes pratiques DevOps :

- Infrastructure as Code
- Ansible Roles
- Variables Ansible
- Templates Jinja2
- Docker Compose
- Sécurité
- Monitoring
- CI/CD




# 1. Création automatique de l'arborescence

Avant de commencer, nous allons générer automatiquement la structure du projet.


Créer le script :
```bash
create-mars-voting-structure.sh
```
Contenu :
```bash
#!/bin/bash

PROJECT=mars-attack-voting

echo "Creating Mars Attack project..."
mkdir -p $PROJECT
cd $PROJECT || exit

# Ansible core

mkdir -p inventory
mkdir -p playbooks
mkdir -p group_vars
mkdir -p host_vars

# Docker role

mkdir -p roles/docker/tasks
mkdir -p roles/docker/handlers
mkdir -p roles/docker/templates

# Voting application role

mkdir -p roles/voting-app/tasks
mkdir -p roles/voting-app/templates
mkdir -p roles/voting-app/defaults
mkdir -p roles/voting-app/vars

# Security role

mkdir -p roles/security/tasks
mkdir -p roles/security/handlers

# Monitoring role

mkdir -p roles/monitoring/tasks
mkdir -p roles/monitoring/templates

mkdir -p files
touch ansible.cfg
touch inventory/hosts.ini
touch group_vars/all.yml
touch playbooks/site.yml
touch playbooks/deploy-voting-app.yml
touch roles/docker/tasks/main.yml
touch roles/docker/handlers/main.yml
touch roles/docker/templates/daemon.json
touch roles/voting-app/tasks/main.yml
touch roles/voting-app/templates/docker-compose.yml.j2
touch roles/security/tasks/main.yml
touch roles/monitoring/tasks/main.yml
touch README.md

echo "Project created successfully"

tree .
```
Exécution :
```bash
chmod +x create-mars-voting-structure.sh
./create-mars-voting-structure.sh
```
